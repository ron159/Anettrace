# Anettrace v0.8.14

## 主要变化

- 修复同名内核符号导致的 Kprobe 挂载失败：采集前区分唯一、缺失和歧义符号，覆盖地址隐藏、同名局部函数及多个编译器后缀候选，保留原有唯一符号路径。
- 默认采集跳过有歧义的可选探针并明确提示覆盖降级；用户通过 `--trace` 点名要求的歧义或缺失函数直接报错，专项诊断继续要求关键探针可用。
- JSONL、原生 Perfetto、极简转换和环形窗口保留 `probe_status`，离线分析报告显示具体探针缺口，避免将正常抓到其他包误认为完整覆盖。
- 新增独立 `__xfrm_policy_check` IPv4 / IPv6 慢路径探针，校验协议族并沿用地址、UID、线程过滤。它保留真实阶段名称，不覆盖包装函数中的快速放行或旁路，也不作为原探针的等价替代。
- 增加符号解析、选择策略、XFRM 过滤和导出状态回归，以及独立网络命名空间内的 XFRM 实际抓包验证脚本。

## 快速使用

正常抓取详细网络路径：

```sh
./anettrace --capture-trace --trace-detail --uid 10187 \
  --duration 10 --output /data/local/tmp/network.pftrace
```

遇到 `probe coverage degraded` 时查看提示中的探针名，或在 Perfetto 元数据中查询 `probe_status`。
明确要求某个函数时可使用 `--trace xfrm4_policy_check`；存在同名歧义时会直接失败。
慢路径专项观测可使用 `--perfetto-events events.jsonl --trace __xfrm_policy_check --trace-detail --proto udp --port 443 --duration 10`，实际没有进入慢路径时不会生成该阶段事件。
