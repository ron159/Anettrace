# Anettrace v0.8.19

## 主要变化

- 将内核配置、版本条件、tracefs 格式和 trampoline 检测移到进程内，减少启动时的外部命令调用。在一台 Android 6.6 设备上，三轮短时采集的启动中位数由 3.31 秒降至 3.22 秒。
- `--debug` 新增探针准备、符号解析、BPF 加载、挂载、采集就绪和首条样本的启动时间点。
- `--traffic --proto tcp|udp` 只加载所选协议的探针。UDP 端点探针无法挂载时继续统计载荷字节，受影响的端点标为未知。

## 快速使用

在设备的 root shell 中运行以下命令。出现 `begin trace...` 后触发待测流量。

```sh
./anettrace --capture-trace --duration 10 --output /data/local/tmp/hook-startup.pftrace --force --debug
```
