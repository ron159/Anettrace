# Anettrace v0.8.11

## 主要变化

- 离线收发性能报告增加五个 Tab，按采集质量、连接概览、Socket 时间线、慢调用和调度时间切换；表格分页并支持键盘切换页面。
- 新增全部或指定 Socket 的时间点概览与事件明细，保留创建 allocation 开始/完成、SYN、SYN-ACK、FIN、RST 的每次观测，以及方向、端点、packet/flow/IP ID 和 TCP 标志、序号等定位信息。缺失时间显示“未观测”。
- Perfetto 单事件入口自动选中对应 tag；后续定位复用同一标签页。按官方接口限制，每次跳转在该页重新载入 trace；已校验的原始字节在报告页缓存。同一时间及持续时间存在多个重叠 tag 时，使用精确 SQL 避免选错事件。
- 本次只修改离线报告、测试及文档，没有修改设备端采集、eBPF 或原生导出逻辑。

## 快速使用

下载并解压 `anettrace-0.8.11-host-tools.tar.bz2`，在解压目录运行：

```sh
python3 -m venv .venv
.venv/bin/pip install -r tools/requirements-perfetto.txt
.venv/bin/python tools/network_report.py analyze capture.pftrace --out report --serve --open
```

已有报告需重新生成，才能使用新的 Tab、Socket 明细和定位链接；无需重新采集，也无需升级设备端二进制。Socket 关键时刻必须已存在于原 trace 中，工具不推断未捕获的创建或关闭阶段。
