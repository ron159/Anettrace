# Anettrace v0.6.5

## 主要变化

- 删除 0.6.4 引入的 `debug.search.*` 副本，详情面板中每个附加参数只显示一份。
- 原字段直接保存为字符串，使端口、包标识、布尔值、流量统计等参数可搜索；
  事件名称、流标签和关联方式保持不变。
- 设备端原生导出与主机端 JSONL 转换同步调整。
- 更新项目内连接诊断 SQL，显式转换数值和布尔参数，保持查询结果类型。

## 快速使用

重新采集 trace，或用新版工具转换原始 JSONL 后，在 Perfetto 顶部搜索框输入 `443`、
`0x1234`、`false` 等值，或 `dport` 等字段名，即可检索对应事件。

搜索为文本匹配，`dport=443` 不再作为完整文本匹配。需要精确筛选时使用：

```sql
SELECT id, ts, name FROM slice
WHERE EXTRACT_ARG(arg_set_id, 'debug.dport') = '443';
```

附加参数的存储类型有变化：数值比较、排序和统计前需使用 `CAST(... AS INT)`；
布尔值为 `true`/`false` 字符串，应使用字符串比较，不能直接转为整数。
原始 JSONL 的数值类型不变。已有二进制 trace 不会自动更新显示或参数类型。
