# Anettrace v0.8.13

## 主要变化

- 更新 README 的正式版下载、SHA-256 校验和 Android 部署示例，补充主机离线报告的获取、解压与运行步骤。
- 说明 eBPF 网络追踪、无需 root 的系统 Perfetto 采集和主机离线分析各自的运行条件；补齐 Socket 时间线、UTC+8 / 相对时间显示及近期仓库文档入口。
- 适配独立挂载于 `/sys/kernel/tracing` 的 tracefs，修复仅检查 debugfs 导致的追踪点和丢包 / TCP reset 原因不可用问题；兼容 kprobe 挂载使用相同路径发现逻辑。
- 修复 TRACING 返回事件的非零返回值被误当作已匹配上下文，导致 monitor 等非上下文模式跳过地址、UID 或线程过滤的问题。
- 沿用旧 debugfs 路径优先规则，同时保留 TRACING / KPROBE 双后端、monitor 与 Android 静态发布方式。

## 快速使用

下载本版 `anettrace-0.8.13-host-tools.tar.bz2`，按 `SHA256SUMS` 校验并解压，在解压目录运行：

```sh
python3 -m venv .venv
.venv/bin/pip install -r tools/requirements-perfetto.txt
.venv/bin/python tools/network_report.py analyze /path/to/capture.pftrace --out report --serve --open
```

生成 HTML / JSON 并在浏览器打开本地报告；已有包含 Anettrace 网络事件的轨迹无需重新采集。
完整安装命令见仓库 README。设备端网络追踪仍需要 root 和允许 BPF 挂载的安全策略。
