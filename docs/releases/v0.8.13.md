## 快速使用

下载本版 `anettrace-0.8.13-host-tools.tar.bz2`，按 `SHA256SUMS` 校验并解压，在解压目录运行：

```sh
python3 -m venv .venv
.venv/bin/pip install -r tools/requirements-perfetto.txt
.venv/bin/python tools/network_report.py analyze /path/to/capture.pftrace --out report --serve --open
```

生成 HTML / JSON 并在浏览器打开本地报告；已有包含 Anettrace 网络事件的轨迹无需重新采集。
完整安装命令见仓库 README；上游取舍和后续验证要求见 `docs/upstream-sync.md`。
