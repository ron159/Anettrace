# Anettrace v0.6.3

本版本允许设备端原生联合采集直接读取自定义 Perfetto textproto 配置，同时继续由 Anettrace
统一管理系统 trace 与网络事件的采集窗口。

## 主要变化

- `--capture-trace` 新增 `--perfetto-config DEVICE_PATH`；
- 自定义配置会复制到 Android SELinux 可访问的 Perfetto 配置目录后启动采集；
- 自动忽略自定义配置根级的 `duration_ms`，普通模式继续由 `--duration` 控制结束时间；
- 环形模式移除固定 `duration_ms`，保持运行到 Ctrl+C 并保存最近 N 秒；
- 注释、字符串以及 data source 内部的同名 `duration_ms` 字段不会被误删；
- `--perfetto-config` 与内置 `--trace-profile full|sched` 明确互斥；
- 拒绝空文件、非普通文件和超过 4 MiB 的配置文件；
- 新增配置过滤单测、CLI 契约、Android smoke 和 Linux/Android CI 检查。

## 快速使用

```sh
adb push perfetto_cfg.pbtxt /data/local/tmp/perfetto_cfg.pbtxt

./anettrace --capture-trace \
  --perfetto-config /data/local/tmp/perfetto_cfg.pbtxt \
  --duration 10 --uid 10187 \
  --output /data/local/tmp/custom-network.pftrace
```

最终 `.pftrace` 仍同时包含常规 Android 系统 trace 和 Anettrace 网络 TrackEvent，不采集或保存
packet payload。
