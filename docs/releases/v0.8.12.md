# Anettrace v0.8.12

## 主要变化

- 离线报告时间默认转换为 UTC+8 时分秒，同时展示距 trace 起点的相对时间；顶部可切换为纯相对时间。
- Socket 创建、SYN/SYN-ACK、FIN/RST 及证据详情统一显示可读时间，时间点保留微秒精度，耗时以 ms / s 展示。顶部给出起点日期，跨日事件另外显示日期。
- 使用轨迹中的真实时钟映射逐个转换显示时刻；没有墙钟映射时明确回退相对时间，不把开机时间或文件时间伪造成 UTC 日期。
- JSON、原始 SQL 和 Perfetto 定位仍保留精确纳秒值，同页定位行为保持不变。本次未修改设备端采集或 eBPF 逻辑。

## 快速使用

更新 `anettrace-0.8.12-host-tools.tar.bz2` 后，用原有轨迹重新生成报告：

```sh
.venv/bin/python tools/network_report.py analyze capture.pftrace --out report --serve --open
```

无需重新采集。打开报告后，默认的“UTC+8 + 相对时间”显示形如 `18:27:59.668340` 和 `+6.874574 s`；如只需比较事件间隔，选择“相对 trace 起点”。
