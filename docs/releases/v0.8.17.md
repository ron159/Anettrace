# Anettrace v0.8.17

## 主要变化

- 缩短网络追踪的启动时间。采集器为内核符号建立一次名称索引，多个探针可以复用。符号表较大的手机尤其受益。
- 保留重名检查、模块符号及编译器后缀匹配。完成探针解析后立即释放索引，申请索引内存失败时回退到逐行查找。

## 快速使用

在设备的 root shell 中运行下列命令。出现 `begin trace...` 后触发待测操作，终端每秒输出流量统计，网络采集窗口为十秒。

```sh
./anettrace --capture-trace --duration 10 --output /data/local/tmp/network.pftrace --force --traffic --interval 1
```
