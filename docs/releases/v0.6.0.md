# Anettrace v0.6.0

本版本把实时线程流量统计与 Perfetto 联合抓取整合为一个进程。执行一条命令即可在终端持续查看
TCP/UDP 应用层收发字节，同时在后台静默记录系统与网络时间线；停止时由同一个生命周期完成清理和
trace 发布。

## 主要变化

- 允许 `--traffic` 与 `--capture-trace` 同时使用；
- 网络 trace 事件保持静默，终端只按 `--interval` 输出流量表；
- 继续使用 traffic 专用 BPF skeleton，保留全部 TCP/UDP 流量统计，不受 Perfetto UDP DNS/53
  flow 范围限制；
- Ctrl+C 或 SIGTERM 会先输出最后一个未满统计区间，再停止 Perfetto、关闭 BPF 链路并保存
  `.pftrace`；
- 支持固定 `--duration` 抓取和 `--ring-buffer` 最近窗口抓取；
- 组合模式下 `--count` 表示流量报告次数，达到次数后统一停止并保存 trace；
- 新增 Linux/Android CLI 契约和 Android 真机联合采集 smoke 覆盖。

## 快速使用

持续运行并在 Ctrl+C 后保存停止前 30 秒：

```sh
./anettrace --traffic --capture-trace --ring-buffer \
  --duration 30 --interval 2 --proto tcp --uid 10187 \
  --output /data/local/tmp/browser-network.pftrace
```

固定抓取 15 秒后自动保存：

```sh
./anettrace --traffic --capture-trace \
  --duration 15 --interval 1 --uid 10187 \
  --output /data/local/tmp/browser-network.pftrace
```

## 行为与兼容性

- 单独使用 `--traffic` 或 `--capture-trace` 的行为保持兼容；
- `--traffic` 仍只接受协议、TID 和 UID 过滤，组合模式不会静默忽略其他过滤条件；
- `--perfetto-events` 和终端逐事件的 `--trace GROUP` 仍是独立模式；
- `APP_TX_KB/APP_RX_KB` 是成功 `sendmsg/recvmsg` 返回的应用 payload，不包含协议头、控制包和
  重传字节；
- 需要 root、BTF、可用的 KPROBE/KRETPROBE，以及设备端 `/system/bin/perfetto`。

Release 继续提供 Android arm64 dual 二进制与归档、主机工具、TCP connect workload、CycloneDX
SBOM 和 `SHA256SUMS`。Linux 继续从源码构建。
