# Anettrace v0.6.6

## 主要变化

- 新增 `--capture-trace --system-trace-only`，只采集系统 Perfetto trace，
  跳过 root 检查、BPF 初始化和所有 Anettrace 网络事件导出。
- 支持采集时长、输出文件或目录、内置 profile、自定义配置及环形缓冲模式。
- 通过标准输入传递配置、标准输出接收 trace，减少非 root 环境中的文件访问限制。
- 明确拒绝 `--uid`、`--traffic`、`--trace-detail` 等不适用的网络参数。
- 检查 Perfetto 子进程异常退出、空输出和临时文件冲突，并加入非 root CLI 回归测试。

## 快速使用

在有系统 Perfetto 访问权限的 `adb shell` 中运行，无需执行 `su`：

```sh
./anettrace --capture-trace --system-trace-only --duration 10 \
  --output /data/local/tmp/system.pftrace

./anettrace --capture-trace --system-trace-only \
  --perfetto-config /data/local/tmp/perfetto_cfg.pbtxt \
  --duration 10 --output /data/local/tmp/custom-system.pftrace
```

自定义配置的顶层 `duration_ms` 仍由 Anettrace 忽略，采集窗口由 `--duration` 控制。
增加 `--ring-buffer` 后持续运行至 Ctrl+C，并保留停止前指定时长的窗口。
无需 root 不代表普通 Android 应用身份拥有系统采集权限；设备 ROM 可能限制部分数据源。
自定义配置若启用系统自身的网络数据源，仍会由 Perfetto 正常采集。
