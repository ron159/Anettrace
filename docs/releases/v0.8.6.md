# Anettrace v0.8.6

修复无 root 手机仅采集系统 trace 时，Perfetto 已启动却输出 0 字节的问题。

## 主要变化

- Android 的 `--system-trace-only` 改为将配置写入 `/data/misc/perfetto-configs`，由 Perfetto 自行在 `/data/misc/perfetto-traces` 创建 trace，避免部分 ROM 的 SELinux 拒绝向继承的 stdout 文件描述符写入。
- 采集结束后，由 Anettrace 将系统 trace 保存到 `--output` 指定的路径，并清理本次临时文件。最终输出和自定义配置仍可放在 `/data/local/tmp`，不再要求配置、Perfetto 输出和最终文件共用目录。
- 环形模式直接将保留窗口写入最终输出目录的暂存文件，不再在 Perfetto 目录中创建裁剪文件，支持无 root 的 Ctrl+C 保存。
- 配置写入失败、系统 trace 缺失或为空时，错误信息补充实际临时路径和原因。保留定时采集、Ctrl+C、环形窗口和自定义配置支持。

## 快速使用

在有系统 Perfetto 访问权限的 `adb shell` 中运行，无需 `su`：

```sh
./anettrace --capture-trace --system-trace-only \
  --trace-profile sched --duration 10 \
  --output /data/local/tmp/system.pftrace
```

自定义配置示例：

```sh
./anettrace --capture-trace --system-trace-only \
  --perfetto-config /data/local/tmp/perfetto_cfg.pbtxt \
  --duration 10 --output /data/local/tmp/custom-system.pftrace
```

系统 Perfetto 仍须支持 `--notify-fd`；可用数据源受设备 ROM 限制。网络/BPF 联合采集
仍需要 root。下载后核对 `SHA256SUMS`，运行 `--version` 确认版本为 `0.8.6`。
