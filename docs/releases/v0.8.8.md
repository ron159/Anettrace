# Anettrace v0.8.8

新增 `--trace-tags` 网络 trace 极简展示模式，便于查看应用收发包的关键时机。

## 主要变化

- 显示 socket 创建区间、应用网络系统调用和 TCP/UDP/ICMP 关键收发包。
- 隐藏关联箭头、socket 生命周期长条、协议层 socket I/O 切片和 packet 镜像轨道。
- 保留 packet 的 socket/packet/skb/flow/io/call ID、IP ID、端点及其他已采集参数。
  晚到的可靠 socket 归属可补到原 packet 上；未知信息不猜测。
- 原生 `.pftrace`、主机采集工具和 JSONL 转换器均支持；可将已有 JSONL 重新生成极简展示。

## 快速使用

```sh
./anettrace --capture-trace --trace-tags --uid 10187 --duration 15 \
  --output /data/local/tmp/network-tags.pftrace
```

`--trace-tags` 与 `--trace-detail`、`--connect-diagnostics` 互斥。
使用方法见[收发链路说明](https://github.com/ron159/Anettrace/blob/v0.8.8/docs/perfetto-chain.md)。

下载后核对 `SHA256SUMS`，运行 `--version` 确认版本为 `0.8.8`。
