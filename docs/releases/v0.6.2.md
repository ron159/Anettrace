# Anettrace v0.6.2

本版本增强 Perfetto 网络事件与 tcpdump/Wireshark 报文之间的对应能力，并修正默认精简模式的
TCP 发送锚点。

## 主要变化

- IPv4 packet 事件新增 `ip_id` 和 Wireshark 风格的 `ip_id_hex`；
- UDP DNS/53 packet 事件新增 `dns_transaction_id` 和 `dns_transaction_id_hex`；
- 十六进制 ID 统一使用小写、四位补零格式，例如 `0x002a`；
- 默认精简模式将 TCP TX 可见锚点移到 `ip_output`/`ip6_output`，确保 IPv4 头和 IP ID 已生成；
- `--trace-detail` 与连接诊断继续保留 `__tcp_transmit_skb` 详细发送阶段；
- 原生 TrackEvent、JSONL 和离线 Perfetto 转换器使用一致的字段契约；
- 只读取 IPv4/DNS 头部元数据，不采集或保存 packet payload。

## IPv6 说明

IPv6 基础头没有 IPv4 `Identification` 的等价字段。普通 IPv6 流继续使用双向五元组
`flow_id`，并结合 TCP `seq/ack/flags`、DNS transaction ID 和时间戳定位具体报文；Flow Label
仅作为辅助信息，不作为唯一 packet ID。

## 快速使用

```sh
./src/anettrace --capture-trace --duration 10 --output anettrace-v0.6.2.pftrace
```

Linux 继续从源码构建，Android 继续提供 arm64 dual 二进制与归档、主机工具、TCP connect
workload、CycloneDX SBOM 和 `SHA256SUMS`。
