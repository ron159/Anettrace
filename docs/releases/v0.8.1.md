# Anettrace v0.8.1

## 主要变化

本次为 v0.8.0 的帮助说明修订版，保留原有 socket、包路径与应用收发关联行为。

- 完善设备 `-h`：明确默认精简模式、`--trace-detail` 详细模式的探针范围与限制，并加入可直接使用的命令示例。
- 明确 `--detail` 仅增加事件附加字段，`--force` 仅放宽无过滤或宽泛 UID 0 的采集检查；`--force` 保留已有过滤条件，不切换精简/详细模式。
- 说明 `--trace-profile` 独立选择系统数据源，`--trace` 与 `--capture-trace` 互斥；详细模式受可用探针、显式选择及排除规则约束。
- 同步主机抓取工具的帮助、README 下载入口与收发链路说明。主机工具仍要求 `--uid` 或 `--pid`，无过滤采集使用设备 CLI 的 `--force`。

## 快速使用

下载并核对 `SHA256SUMS` 后，在设备上确认版本和完整参数：

```sh
./anettrace --version
./anettrace -h
```

在 root shell 中抓取目标应用，将 UID 替换为实际值：

```sh
# 默认精简模式
./anettrace --capture-trace --uid 10187 --duration 10 \
  --output /data/local/tmp/compact.pftrace

# 详细模式
./anettrace --capture-trace --uid 10187 --trace-detail --duration 10 \
  --output /data/local/tmp/detailed.pftrace
```

详细模式展示当前设备可挂载的已注册网络探针，不是完整内核调用树。需要查询 socket、包与收发调用的关联时，可使用 host-tools 包中的 `tools/perfetto_sql/network_chain.sql`。
