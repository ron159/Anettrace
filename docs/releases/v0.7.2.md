# Anettrace v0.7.2

## 主要变化

- 修复 Android arm64 上 `skb/consume_skb` 和 `net/netif_receive_skb` 挂载失败、对应包阶段缺失的问题。共用处理路径原先把 tracepoint 上下文当作函数寄存器读取，访问范围超过真机上的 24 字节记录，导致内核以 `EACCES` 拒绝挂载。
- 在函数探针入口解码收发参数，共用事件处理逻辑只使用已解码的值，保留应用调用时间片和流/包关联。
- tracepoint 不可用时显示具体错误码和覆盖缺口；加强真机回归检查，挂载失败不再因程序仍能启动而被判定为通过。

## 快速使用

```sh
./anettrace --capture-trace --uid 10187 --duration 20 --output game.pftrace
```

已在 PKC130 / 6.6.118-android15 内核上验证紧凑和详细模式挂载成功，完整 Perfetto 采集退出码为 0，包含恢复的 `consume_skb`、网络接收阶段及应用 I/O 关联，事件丢失数为 0。未修改设备安全设置；其他内核仍需各自实测。编译由 GitHub Actions 完成。

Perfetto 的 `No PTY` 提示针对交互终端中的 Ctrl+C；定时采集由 Anettrace 主动通知 Perfetto 结束并检查退出状态，该提示本身不表示采集失败。
