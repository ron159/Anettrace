# Anettrace v0.8.18

## 主要变化

- 缩短联合采集从启动到 `begin trace` 的等待。内核符号解析只为本轮探针建立索引，系统 Perfetto 与网络探针并行准备。网络采集时长从就绪后开始计算，系统轨道可以包含一段探针加载过程。
- 极简模式 `--trace-tags` 保留 UDP 收包与应用接收调用之间可直接验证的关联。可按 `packet_id` 和 `call_id` 查回对应的包与调用。

## 快速使用

在设备的 root shell 中执行下列命令。出现 `begin trace...` 后触发待测操作，终端每秒打印流量统计。在 Perfetto 中点选 UDP 收包，复制 `packet_id` 即可查找对应的接收证据。

```sh
./anettrace --capture-trace --duration 10 --output /data/local/tmp/my_trace.pftrace --force --traffic --interval 1 --trace-tags
```
