# Anettrace v0.8.16

## 主要变化

- Perfetto 抓取遇到 BPF perf 缓冲区内存分配失败时，自动减半重试，成功后记录实际分配的每 CPU 页数。低内存设备可继续使用原有抓取命令。
- 显式指定 `--perf-buffer-pages` 时按指定容量分配。默认容量最低尝试到 64 页/CPU。

## 快速使用

```sh
./anettrace --capture-trace --uid 10187 --duration 10 \
  --output /data/local/tmp/network.pftrace
```

缓冲区缩小后，突发流量仍可能造成采集事件丢失，可在轨迹结束元数据中查看丢失计数。

[抓取缓冲区说明](https://github.com/ron159/Anettrace/blob/v0.8.16/docs/capture-buffers.md)
