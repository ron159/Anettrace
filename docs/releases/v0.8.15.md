# Anettrace v0.8.15

- 修复原生抓取在 perf 回调内同步关联、编码、写盘导致内核缓冲区长期无法释放的问题。
  新增 32 MiB 有界异步导出队列，停止时关闭生产并排空已接收事件，避免取消抓取丢弃队列尾部。
- Perfetto 默认 perf 数据区调整为 16 MiB/CPU（4 KiB 页设备为 4096 页/CPU），新增
  `--perf-buffer-pages`，支持 64..16384 范围内的 2 的幂。普通终端跟踪仍默认 1024 页/CPU。
- 原生抓取的丢失警告在结束时汇总；内核和导出队列丢失均进入完整性统计，队列丢失另行标记。
- 新增真实 pthread 回归测试，覆盖慢导出、溢出计数、事件数据生命周期、FIFO、环形跨界与退出排空。

内存评估与参数说明见 [抓取缓冲区](../capture-buffers.md)。8 核、4 KiB 页设备上，perf 数据区
从约 32 MiB 增至 128 MiB，加上固定 32 MiB 队列后约 160 MiB；持续过载仍可能丢事件。
