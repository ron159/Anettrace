# Anettrace v0.6.4

## 主要变化

- 所有导出的网络事件附加参数新增 `search.<key>` 字符串副本，内容为 `key=value`，
  使端口、布尔值、地址、包标识、流量统计和连接诊断参数均可通过 Perfetto 顶部搜索框定位。
- 保留原始参数类型，现有 SQL 查询、简洁事件名称与流关联方式保持兼容。
- 设备端原生采集与主机端 JSONL 转换使用一致的搜索格式。

## 快速使用

打开新版本生成的 trace，在顶部搜索框输入 `dport=443`、`ip_id_hex=0x1234`、
`dns_transaction_id_hex=0x1201` 或 `terminal=false`，然后通过前后搜索结果跳转定位事件。

搜索为文本包含匹配，并非 SQL 精确字段过滤。`dport` 是当前包的目的端口，收包时通常
对应手机本地端口。已有 trace 需要重新采集，或使用新转换工具重新转换原始 JSONL。
搜索副本会增加 trace 文件大小，也可能让环形缓冲更早达到固定字节容量上限。
