# Anettrace v0.8.7

修复无 root Android 手机采集系统 trace 时的 SELinux 路径限制，并兼容不支持
`--notify-fd` 的旧版系统 Perfetto。

## 主要变化

- 启动前探测 Perfetto 的实际命令行能力。支持 `--notify-fd` 时继续等待数据源确认；不支持时使用前台兼容采集，不再因未知参数直接失败。兼容模式会明确提示无法确认数据源就绪，时长从进程启动后计算。
- 两种模式都保留子进程退出检查、Ctrl+C 停止保存、错误和空 trace 校验。探测失败或超时，以及新版 Perfetto 的就绪确认失败，仍会报错，不会静默降级。
- 主机采集工具同步兼容旧版 Perfetto，manifest 明确以 `started_unconfirmed` 区分进程已启动和数据源已确认。
- Android 配置临时写入 `/data/misc/perfetto-configs`，由 Perfetto 自行在 `/data/misc/perfetto-traces` 创建 trace，再由 Anettrace 保存到 `--output`。最终输出和自定义配置仍可放在 `/data/local/tmp`。
- 环形窗口直接裁剪到最终输出目录的暂存文件，避免无 root shell 在 Perfetto 目录中创建裁剪文件失败；采集完成后清理本次临时文件。

## 快速使用

在有系统 Perfetto 访问权限的 `adb shell` 中运行，无需 `su`：

```sh
./anettrace --capture-trace --system-trace-only \
  --trace-profile sched --duration 10 \
  --output /data/local/tmp/system.pftrace
```

自定义配置使用 `--perfetto-config /data/local/tmp/perfetto_cfg.pbtxt` 替代
`--trace-profile sched`；增加 `--ring-buffer` 可持续采集，Ctrl+C 保存最后
`--duration` 秒。可用系统数据源受设备 ROM 限制，网络/BPF 联合采集仍需要 root。

下载后核对 `SHA256SUMS`，运行 `--version` 确认版本为 `0.8.7`。
