# Anettrace v0.8.9

## 主要变化

- 新增离线通用收发性能报告：读取已有 `.pftrace`，生成 HTML 与 JSON，集中查看采集质量、连接概览、慢调用排行和调用窗口内的调度时间。
- 结果提供 Perfetto 定位入口、精确纳秒时间与定位 SQL；本地服务校验原文件 SHA-256，浏览器通过 postMessage 打开轨迹，避免把报告对应到错误文件。
- 统一兼容原生导出器的字符串标注和 JSONL 转换器的类型化标注，支持极简 `--trace-tags` 轨迹；生命周期、调度或采集结束数据缺失时明确提示。
- 排除 socket packet 镜像和协议层重复统计，区分字节与批量调用消息数；未完成和裁剪调用保留证据但不进入耗时排行。
- host-tools 包含完整报告工具、HTML 模板、文档和 JSON schema。

## 快速使用

```sh
python3 -m venv .venv
.venv/bin/pip install -r tools/requirements-perfetto.txt
.venv/bin/python tools/network_report.py analyze capture.pftrace --out report --serve --open
```

报告入口见 `docs/network-performance-report.md`。查看调度分解需要包含 sched 数据的轨迹；BPF 丢事件不等于网络丢包，其他线程状态不等于网络等待。
