# Anettrace v0.6.1

本版本同步上游兼容性修复，并完善命令行帮助页版权信息。

## 主要变化

- 修复 iptables 名称读取到事件缓冲区时的大小与内核兼容问题；
- 缓存内核符号查询结果，避免重复扫描 `/proc/kallsyms`；
- 保护新内核上的 TCP 定时器字段读取，避免字段不存在导致加载异常；
- `anettrace -h` 显示作者 `ron` 与 [GitHub 仓库](https://github.com/ron159/Anettrace)；
- 产品版本、CLI、artifact、tag 和 Release 统一使用 `0.6.1`。

## 快速使用

```sh
./src/anettrace --help
```

Linux 继续从源码构建，Android 继续提供 arm64 dual 二进制与归档、主机工具、TCP connect
workload、CycloneDX SBOM 和 `SHA256SUMS`。
