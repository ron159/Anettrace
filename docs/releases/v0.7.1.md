# Anettrace v0.7.1

## 主要变化

- 修复 v0.7.0 在 Android 真机上加载 kprobe eBPF 失败、退出码 255 的问题。受影响 arm64 构建的三层调用栈达到 544 字节，超过内核的 512 字节上限。
- 将普通和扩展探针事件缓冲放入每 CPU map，并完整初始化；保留现有事件格式、普通 UDP、系统调用时间片和流/包关联。
- 加载失败时显示错误码与 verifier 日志开关，方便区分内核校验、权限及兼容性问题。

## 快速使用

```sh
./anettrace --capture-trace --uid 10187 --duration 20 --output game.pftrace
```

排查加载问题时在原命令中加上 `--libbpf-debug` 并保留完整输出。构建在 GitHub Actions 执行。已在 PKC130、Android 17 / 6.6.118-android15 内核上对照复现旧版失败，并验证修复版普通、详细模式成功加载和采集本地 UDP，事件丢失数为 0。仓库提供 `tests/android-bpf-load-smoke.sh` 用于在目标内核重复验证；其他内核仍需各自实测。
