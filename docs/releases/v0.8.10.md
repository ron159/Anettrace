# Anettrace v0.8.10

## 主要变化

- 新增通用离线收发性能报告：读取已有 `.pftrace`，生成 HTML 和 JSON，查看采集质量、连接概览、慢调用排行，以及调用窗口内的运行、可运行等待、其他状态和未覆盖时间。
- 每个结果提供定位 SQL 与精确纳秒时间；通过校验 SHA-256 的本地服务在 Perfetto 打开原始轨迹。支持极简 `--trace-tags`，保留缺失证据和未知状态的边界。
- 修正 Linux 7.0 运行器上的唤醒集成测试预期：继续要求真实 wake/run 时间、正确时间顺序和禁止伪造 waker 身份；在旧内核上继续验证任务上下文和真实 waker。捕获代码对未经验证的 7.x 上下文布局仍返回 unknown。
- host-tools 包含报告脚本、HTML 模板、文档与 JSON schema。v0.8.9 的发布被旧集成测试预期阻断，已创建的标签保持不变，本次正式发布使用下一补丁版本。

## 快速使用

```sh
python3 -m venv .venv
.venv/bin/pip install -r tools/requirements-perfetto.txt
.venv/bin/python tools/network_report.py analyze capture.pftrace --out report --serve --open
```

详见 `docs/network-performance-report.md`。查看调度分解需要包含 sched 数据的轨迹；BPF 丢事件不等于网络丢包，其他线程状态不等于网络等待。
