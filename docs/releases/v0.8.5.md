# Anettrace v0.8.5

本版围绕应用收发流程补齐基础采集和易用性。

- 主机工具新增 `--package`，精确解析应用 UID，提示共享 UID 范围。新增 `--tid`，保留旧 `--pid` 的线程过滤语义。
- 新增可选 `--wakeup-chain`：在网络 syscall 上保留直接唤醒来源、唤醒时间和进入 CPU 的时间。区分任务与中断上下文、无新唤醒的恢复运行和未知状态。
- 新增可选 `--rx-context`：缓存早期未归属 RX，获得同一 skb 实例的目标 socket 证据后补全。缓存有时间和容量上限；未知事件不写入轨迹，记录未补全原因的计数。
- Perfetto 补齐已采到的 socket 状态、收发队列长度、TCP 在途/重传计数与 qdisc 队列状态，原生导出与 JSONL 转换一致。
- 采集就绪等待网络缓冲区和 Perfetto 数据源确认；请求时长从就绪后计算，启动取消与失败会清理子进程。

```sh
python3 tools/capture_android_trace.py \
  --package com.example.app --anettrace ./anettrace \
  --wakeup-chain --rx-context --trace-detail \
  --duration 15 --out output/app-flow
```

网络采集仍需已 root 的 Linux/Android 环境和可用内核探针；系统 Perfetto 需支持
`--notify-fd`。新开关默认关闭。直接唤醒上下文不是完整业务因果链，RX 补全也不跨
GRO/GSO/clone 产生的新 skb 实例。使用方法和字段含义见
[应用收发链路采集](https://github.com/ron159/Anettrace/blob/v0.8.5/docs/packet-flow-foundations.md)。

下载后核对 `SHA256SUMS`，运行 `--version` 确认版本为 `0.8.5`。
